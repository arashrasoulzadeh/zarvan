The engine
Everything starts with the world.
ZARVAN keeps simulation, rendering, and game-specific systems separate, so the core remains portable and testable.
01 / CORE
Deterministic simulation
Fixed timesteps, seeded randomness, ECS, and headless tests. Run the same world on a phone, server, or CI.
02 / SHELL
Flutter when you need it
Rendering, input, audio, camera, and platform services live at the edge. The simulation stays pure Dart.
03 / DATA
Content as data
Serialize worlds to JSON, author levels as data, and keep genre packages focused instead of building one giant framework.


      
A frame in three steps
Simple enough to reason about.
Keep the loop visible. Each tick has a clear boundary between input, simulation, and presentation.
01 / Observe
Read input, commands, or an agent WorldView without changing authority.
02 / Simulate
Advance systems with a fixed timestep and deterministic rules.
03 / Present
Let Flutter render the resulting world and connect platform services.


      
Agent-native by design
Let agents play without giving up authority.
Agents observe a read-only view and propose actions. The engine validates and applies them. State can be logged, replayed, evaluated, and patched as ordinary JSON.
ObserveRead a compact WorldView without mutating the simulation.
ActSubmit a Move, Attack, Build, or custom command through the operation registry.
EvaluateReplay the same JSON state and compare outcomes in CI or a benchmark.
AuthorPatch data-driven levels, dialogue, and entities without touching renderer code.
